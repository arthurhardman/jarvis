Política de Privacidade

Última atualização: 28 de outubro de 2026.

O Jarvis é um assistente de voz pessoal, usado apenas pelo seu autor, Arthur Augusto Paula Hardman. Esta página explica quais dados ele acessa, para quê, onde eles ficam e como revogar o acesso.

1. Dados da conta Google

Com a autorização do usuário, o Jarvis acessa:

  • Google Agenda (calendar): para listar, criar, alterar e apagar eventos, apenas quando o usuário pede por voz.
  • Google Tarefas (tasks): para listar, criar e concluir tarefas, apenas quando o usuário pede por voz.
  • Gmail (gmail.readonly e gmail.compose): para buscar e ler e-mails e criar rascunhos, apenas quando o usuário pede por voz. O Jarvis nunca envia e-mails; os rascunhos ficam no Gmail para o usuário revisar e enviar.
  • Google Drive (drive.readonly): para procurar arquivos e ler o texto de documentos, planilhas e apresentações, apenas quando o usuário pede. Nenhum arquivo é alterado.
  • Contatos (contacts.readonly): para encontrar telefone, e-mail ou aniversário de um contato, apenas quando o usuário pede. Nenhum contato é alterado.

Esses dados são usados somente para responder aos pedidos do próprio usuário. Eles não são vendidos, não são compartilhados com terceiros para publicidade, não são usados para criar perfis e não são usados para treinar modelos de IA.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

2. Voz e texto

  • Áudio da fala: enviado ao Microsoft Azure AI Speech para ser transformado em texto. O Jarvis não grava nem guarda o áudio.
  • Texto do pedido: enviado à API da Anthropic (Claude), junto com os dados da conta Google necessários para responder (por exemplo, os eventos do dia ou o trecho de um e-mail pedido). Pela política da Anthropic, dados enviados pela API não são usados para treinar modelos.
  • Resposta falada: gerada pelo Microsoft Azure AI Speech a partir do texto da resposta.

3. O que fica guardado e onde

  • Histórico recente da conversa: guardado no computador do usuário e descartado depois de 6 horas sem uso.
  • Memória de longo prazo: fatos que o usuário pede para lembrar, numa nota de texto no computador do usuário, que ele pode ler, editar ou apagar.
  • Autorização do Google: o token de acesso fica num arquivo local, legível só pelo usuário do computador.

O Jarvis não mantém banco de dados na nuvem com dados do usuário.

4. Como revogar o acesso

O acesso à conta Google pode ser removido a qualquer momento em myaccount.google.com/permissions, escolhendo "Jarvis" e depois "Remover acesso". Apagar os arquivos locais do Jarvis elimina o histórico, a memória e o token.
